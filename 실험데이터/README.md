# 실험데이터 (X-ray Void 검사 DOE)

4개 실험 데이터셋을 압축 해제해 정리한 폴더입니다. 각 폴더 하위는 장비 원본 결과(CSV·이미지·DIEMap 등)입니다.

## 폴더 구성

| 폴더 | 내용 | 파라미터 출처 |
|------|------|---------------|
| `공정모델링_DOE_2anchor_3anchor_Fmin32_측정직경모델/` | 26µm·86µm 2-anchor DOE (D26-xx, D86-xx) | **내장 엑셀** `*.xlsx` (실험별 kV·R·F·W) |
| `공정모델링_실험런시트_43런/` | 43런 핵심판 실행분 (kV1~4, R1~6, F32/F64, W4/W6) | **내장 엑셀** `*.xlsx` (Phase1~4 시트) |
| `TEST/` | kV·W 스윕 (TEST1~6) | **폴더명에 이미 표기** (예: `TEST_60_4` = 60kV·4W) |
| `TB500M_T_TEST_RUN/` | TB500M RUN01~13 + BUMPSIZE1/2 | **폴더명 추가함** (아래 매핑, 기존 브랜치 RunID 대조) |

## 파라미터 참조 방법

- **DOE / 43런**: 각 폴더 안의 엑셀 시트에 실험(Global_Run_ID / Run)별 파라미터가 적혀 있습니다.
  - 예: `D26-01`=60kV·R0.5·F64·W4(Center), `D26-06`=60kV·R0.35·F128·W4 등.
  - `D26-01_03` 폴더는 **1~3번 실험(Center 3반복)을 한 번에 진행**한 것이라 결과 폴더가 `17-1/17-2/17-3` 3개입니다. `D86-01_03`도 동일.
- **TEST**: 폴더명 `TEST_(kV)_(W)` 형식으로 파라미터가 이미 들어 있어 그대로 두었습니다.
- **TB500M**: 원본은 `TB500M_T_TEST_RUN1` 처럼 파라미터가 없어, **기존 브랜치 결과 파일과 RunID(파일명 `_NNNN`)를 대조**해 파라미터를 폴더명에 추가했습니다.
