## 결론 — "결과 A": 정점은 60, 그리고 창이 매우 좁고 비대칭

- **포물선 정점 kV\* = 59.89 ≈ 60** (1차 회귀 kv*=59.96과 일치) → **레시피 kV\*≈60 확정, 보정 불필요.**
- **정점 최대 Q = 0.988** → 26µm은 약 1.2% 언더사이즈가 구조적 한계(정점에서도 100% 못 맞춤).
- **kV60만 게이트 통과, ±0.5kV는 둘 다 탈락** → 창이 ±0.5kV보다도 좁음.
- **비대칭**: +0.5kV(60.5)는 **7.8%p** 급락, −0.5kV(59.5)는 3.0%p 하락 → **높은 쪽이 2.6배 더 위험.**

### 실무 반영
- 트림 폭을 **±0.5 → 실질 ±0.3kV 이내**로 더 좁혀야 함(±0.5는 이미 게이트 밖).
- 세팅 오차가 불가피하면 **약간 낮게(kV↓) 치우치는 게 안전** — 높은 쪽 낙폭이 더 큼.
- kV 캘리브레이션/드리프트 관리가 직경 정확도의 **최대 리스크**임이 재확인됨.
