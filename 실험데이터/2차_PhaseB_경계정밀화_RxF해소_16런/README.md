### ■ kV 창(window) 발견 — 파라미터 이상 아님

당초 "kV61이 예상보다 낮다 → 파라미터 오류 의심"으로 봤으나, **파라미터는 정상**이고 장비 die-level 평균과도 정확히 일치합니다. 실제 발견은:

- **kV60 정점이 1차 3점(58/60/62) 포물선이 그린 것보다 훨씬 날카롭다.** kV60=Q0.97~0.99인데 **kV61에서 이미 Q0.75~0.83(≈20µm, 언더사이즈)로 급락** — 포물선 보간 예측(kV61≈0.93)과 크게 다름.
- kV61·kV62가 거의 같은 언더사이즈 대역이고, R에 따라 61<62인 경우도 있음(정점 이탈 시 응답 불안정 신호).
- **결론: 양호 kV창은 좁다(사실상 kV60 ±0.5).** 레시피 계산기의 "±1kV 트림" 안내는 과대 — kV61이면 이미 ~20% 언더사이즈. **kV 캘리브레이션/드리프트 관리가 직경 정확도의 최대 리스크.**
