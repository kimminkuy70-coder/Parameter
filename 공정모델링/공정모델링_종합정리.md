# 공정 모델링 종합 정리 — 무엇을 정확히 측정하고, 어디까지 고려했나

X-ray void 검사(Nordson XM8000)에서 **PD 직경(D)을 넣으면 kV/R/F/W를 추천**하는 하이브리드 모델(Python 엔진 + Excel 계산기)의 전체 요약입니다.

---

## 1. 한 문장 요약

> **자재 직경(D)만 넣으면, 그 자재의 범프 "직경"을 오차 20% 이내로 정확히 재는 kV/R/F/W 레시피를 자동으로 뽑아준다. 단 "void를 정확히 재는가(진짜 불량을 놓치는가)"는 실제 void 샘플이 없어 아직 검증 못 함.**

---

## 2. 이 모델이 "정확히" 측정하는 것

| 측정 대상 | 상태 | 근거 |
|---|---|---|
| **범프 직경(측정직경 = PD)** | ✅ **확정** | kV60 정점에서 Q_dia 0.98~1.00, 반복 σ 작음 |
| **거짓 불량(False NG, 정상을 불량으로 오판)** | ✅ **확정** | kV62+극단R만 위험, 운영점(kV60·R0.5) 거짓NG 0% |
| **검사 시간(tact) 근사** | 🔶 예비 | bump수·F 기반, R²≈0.33(예측변수 보강 필요) |
| **진짜 불량 놓침(False OK)** | ❌ **미검증** | 웨이퍼가 void-free라 검출 실패를 잴 대상이 없음 |

**핵심 구분**: 이 모델은 "직경 정확도"와 "거짓 불량 방지"는 완결했고, "진짜 void 검출 능력"은 void 샘플이 있어야만 확인 가능합니다.

---

## 3. 각 파라미터를 어떻게 정하나 (메커니즘)

D가 주어지면 네 파라미터가 **서로 다른 오차원**을 각자 담당합니다.

| 파라미터 | 담당 | D 주어지면 | D 의존성 |
|---|---|---|---|
| **kV** | 직경 정확도 | 측정직경=PD 되는 **정점(≈60)에 고정**, ±0.5kV만 트림 | 거의 무관(26·86µm 둘다 ~60) |
| **R** | void 해상도 | N8 게이트 되는 가장 거친 **R = D·√0.08 / N8_MIN** | D에 비례 |
| **F** | 재현성(노이즈) | 직경 무영향 → **최소 32**(tact 절약) | 무관 |
| **W** | 밝기(SNR) | 직경 무영향 → **4 고정** | 두께 의존(현재 자재는 4) |

**요약**: `kV=정확도, R=해상도, F=재현성, W=밝기`. 직경은 오직 kV가 지배하고, R/F/W는 직경엔 무영향이라 각자 다른 목적(해상도/시간/밝기)으로 최소화합니다.

## 4. 어디까지 고려했나 — 교호작용 전수 판정

kV·R·F·W 4인자의 모든 쌍을 **직경·거짓NG 관점에서** 검증했습니다.

| 교호작용 | 상태 | 결론 |
|---|---|---|
| kV×R | ✅ 있음 | kV60 정점이 날카로움(kV61이면 20% 언더) + kV62·극단R만 거짓void |
| kV×F | ✅ 없음 | 위험지점에서도 F 무관하게 0% |
| kV×W | ✅ 없음 | 위험지점에서도 W 무관하게 0% |
| R×F | ✅ 해소완료 | 극단R에서도 F는 직경 무영향. R0.35이 F32에서 완벽 작동 |
| R×W | ✅ 해소완료(직경) | 86µm 2×2 기존데이터로 0.14%p(노이즈). void쪽만 샘플 필요 |
| F×W | ➖ 정의불가 | 안전구간에서 응답이 전부 0이라 볼 변동 없음 |
| kV×D, R×D | ✅ 검증됨 | kV*≈60 자재무관 / R=D√0.08/N8은 정의상 D의존 |

**결론: 직경·거짓NG 관점 교호작용은 전부 확정.** 현재 2자재(26·86µm)로 추가할 순수 교호작용 실험은 **없음**.

## 6. 자주 나올 질문 (FAQ)

**Q1. 왜 kV가 60인가? 자재가 달라도 60인가?**
kV–직경은 포물선이고 그 정점(측정직경=PD 되는 지점)이 26µm·86µm 둘 다 ≈60입니다. kV*(D) 직선의 기울기가 −0.00117로 사실상 자재 무관. 그래서 어떤 D를 넣어도 시작 추천은 ~60.

**Q2. ±1kV 트림해도 되나?**
아니요. PhaseB 실측상 **kV61이면 이미 ~20% 언더사이즈**입니다. 봉우리가 날카로워 **트림은 ±0.5kV 이내**여야 하고, kV 캘리브레이션/드리프트가 직경 정확도의 **최대 리스크**입니다. (진짜 정점이 60인지 59.5/60.5인지는 B3 3런으로 확정 예정.)

**Q3. R/F/W는 왜 회귀 모델이 정해주지 않고 다른 기준으로 정하나?**
회귀가 "R/F/W는 직경에 영향 없다(계수≈0)"고 정직하게 답했기 때문입니다. 영향이 없으면 "직경 관점 최적값"이 존재하지 않으므로, 그 자유도를 **각자의 진짜 역할**(R=void 해상도, F=시간, W=밝기)로 넘긴 것입니다. 이는 사실상 제약조건 최적화(직경 게이트 + N8 게이트 만족하며 tact 최소)를 손으로 푼 것과 같습니다.

**Q4. 오차 기준이 왜 20%인가?**
게이지 R&R(측정시스템분석, AIAG MSA/ISO 14253) 규칙: 측정오차 ≤ 공차의 10%=우수, 10~30%=허용. 10%(우수)는 86µm만 통과하고 26µm은 구조적 탈락 → 같은 이론의 '허용' 등급 안에서 **자재 무관 통일값 20%**를 채택. 이에 따라 N8 게이트 = 2√2/ε = 14.

**Q5. void는 왜 못 재나? 데이터에 void 644건 있다며?**
그 644건은 전부 **kV62 아티팩트(거짓 void)**입니다. 같은 bump가 kV62에서 8~18%인데 kV60·58에선 0.00%. 웨이퍼 자체는 void-free라, "진짜 void를 정확히 재는가"는 잴 대상이 없어 검증 불가. 이건 실험을 더 해서 풀리는 게 아니라 **진짜 void 샘플**이 있어야만 풀립니다.

**Q6. void 샘플을 정상 자재 긁어서 만들면?**
안 됩니다. 표면 스크래치는 X-ray 투과에 거의 영향 없어 void%로 안 변환됩니다. 실제 void는 bump 내부 공동이라 본딩/리플로우 불량으로 만들거나 기존 불량 웨이퍼를 확보해야 합니다.

**Q7. False OK 위험이 실제로 얼마나 되나?**
간접 논거상 낮아 보입니다(0.1% 미세특징도 잡는 감도면 8% void는 훨씬 쉽게 검출). 그러나 이는 나쁜 조건(kV62)에서 본 감도이고 오차 규모가 달라 **정황 증거일 뿐 실측 검증이 아닙니다**. 소형이라도 진짜 void 샘플 1개면 확정됩니다.

**Q8. 10µm 같은 더 작은 자재도 되나?**
외삽상 R≈0.2에서 N8≈14로 게이트는 통과 가능하나 **실측이 없어 미검증**입니다. 26µm의 정점이 이미 날카로운 걸 보면 더 작은 자재는 kV 창이 더 좁을 수 있어 별도 확인이 필요합니다.

**Q9. 새 자재/조건이 생기면 모델을 다시 만들어야 하나?**
아니요. `pipeline.py`가 엔진이라 엑셀에 런을 추가하고 **재실행 한 번**이면 계수·뷰·계산기가 갱신됩니다. 3-anchor로 확장해도 동일.

**Q10. 이 모델을 실제 라인에 어떻게 쓰나?**
`레시피_계산기.xlsx`의 노란칸에 PD 직경(과 목표 bump수)만 넣으면 kV*/R상한/R추천/F/W/예상tact가 자동으로 나옵니다. 오퍼레이터는 kV*를 시작점으로 ±0.5 트림해 측정직경=PD를 맞추면 됩니다.
