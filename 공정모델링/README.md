# 공정 모델링 (하이브리드: Python 엔진 + Excel 계산기)

DOE 38런(`../실험데이터/`) 실측을 회귀해 **PD 직경 → 추천 kV/R/F/W** 모델을 만듭니다.

## 구조
```
공정모델링/
├── pipeline.py            ← 엔진(Python): CSV 취합 → 회귀 → 계수·뷰·계산기 생성
├── 레시피_계산기.xlsx      ← 산출물(Excel): 오퍼레이터 front-end (PD 입력→추천)
│    · 시트: 레시피_계산기 / 파라미터_메커니즘 / 오차기준_근거 / 모델계수
├── outputs/
│   ├── run_level_summary.csv    런별 요약(Q_dia·N8·게이트·tact·bump수)
│   ├── bump_level_merged.csv    bump별 결과 + DOE 조건(회귀/분석 원천)
│   ├── model_coefficients.json  직경(kV²)·kV*(D)·tact 계수
│   └── views/                   직경Gate·N8·tact·DOE주효과 그림(PNG)
└── README.md
```

## 실행
```bash
cd 공정모델링 && python3 pipeline.py
```
새 런이 추가되면(예: 3-anchor 57런) 엑셀만 채우고 **재실행 한 번**이면 계수·계산기가 갱신됩니다.

## 파라미터 메커니즘 — 직경 D가 주어지면 각 값을 어떻게 정하나

각 파라미터는 **서로 다른 오차원(error source)** 을 담당합니다. 모델은 D가 주어지면 각각을 자기 목표에 맞춥니다.

| 파라미터 | 무엇을 조절(물리) | D가 주어지면 | D 의존성 |
|---|---|---|---|
| **kV** | X-ray 투과·대비 → threshold가 잡는 범프 경계 위치 → **측정직경** | 측정직경=PD 되는 **포물선 정점(≈60)** 에 고정 후 ±1kV 트림. **정확도** 담당 | 거의 무관(26·86µm 둘다 ~60) |
| **R** | 픽셀 크기 → 8% void가 몇 픽셀(N8)로 표현되나 → **픽셀화 오차(2/N8)** | N8 게이트 되는 **가장 거친(빠른) R = D·√0.08/N8**. **해상도** 담당 | D에 비례(클수록 R↑ 가능) |
| **F** | 여러 장 평균 → **랜덤 광자노이즈** 저감(∝1/√F). 측정직경·N8은 불변 | 노이즈 σ가 예산 안에 드는 **최소 F(≥32)**. **재현성** 담당 | 무관(조건별 σ로 결정) |
| **W** | X-ray 선속(밝기) → 광자부족 영역 SNR. **시간은 안 늘어남** | 얇은 범프는 4 고정. 두꺼운 범프 내부가 어두울 때만 ↑. **밝기** 담당 | 두께 의존(현재 자재는 4) |

**한 줄 요약**: `kV=정확도, R=해상도, F=재현성, W=밝기`. 네 오차원이 독립이라 각각 따로 목표에 맞춥니다.
- kV는 **직경 정확도**만 담당(±2kV에 8%/kV로 급변, 그래서 정점 고정).
- R은 **void 해상도**만 담당(작을수록 픽셀↑ 정밀하지만 광자부족으로 측정 붕괴 위험 → 하한 존재).
- F·W는 **직경·N8을 못 바꾸고** 노이즈·밝기만 손댐. 단 광자부족으로 측정이 실패하는 걸 막아 **측정 성립 여부**에는 관여.

## 오차 기준 ε = 20% (자재 무관 통일)

- **근거 이론**: 게이지 R&R(측정시스템분석, AIAG MSA / ISO 14253) — 측정오차 ≤ 판정공차의 **10%=우수, 10~30%=허용, >30%=불가**.
- **왜 20%**: 8% void 판정선에 적용. **10%(우수)는 86µm만 통과**하고 26·10µm은 구조적 탈락. 같은 이론의 **'허용' 등급 범위(10~30%) 안에서 통일값 20%** 를 채택 → 자재마다 기준을 바꾸지 않고 동일 원칙 적용.
- **총오차 구성**: `총오차 = √(픽셀화² + 노이즈²)`. 픽셀화=2/N8(R로 결정, 계통), 노이즈=2σ(F/W로 결정, 랜덤).
- **N8 게이트 유도**: 픽셀화·노이즈 균등분할 → 각 ≤ ε/√2 ≈ 14.1% → 픽셀화 2/N8 ≤ 14.1% → **N8 ≥ 2√2/ε = 14**. (ε=10%였다면 29)
- **효과**: N8≥14로 완화하니 86µm(여유)·**26µm(R≤0.5, N8≈14.7 통과)**·10µm(R≈0.2에서 N8≈14, 측정 성공 시)까지 달성 가능.

> ※ 10µm은 실측 없이 외삽. 26µm의 R하한 0.35도 F32까지만 확인 — F를 올리면 더 낮출 여지(R×F 미검증).

## 모델 요약 (현재 38런 기준)
| 모델 | 형태 | 결과 |
|------|------|------|
| 직경 | ln_Q = b0 + b_kV·kV + b_kV2·kV² + b_R·R + b_F·F + b_W·W (anchor별) | **kV–직경은 포물선**, kV*≈60(D 거의 무관), R²=0.93(26µm)/0.96(86µm) |
| kV*(D) | 2 anchor 직선 | kV*(D) ≈ 60 |
| N8 게이트 | N8 = 측정직경·√0.08 / R ≥ **14** (ε=20%) | 통과 27/38, 직경+N8 동시 17/38. **26µm도 R≤0.5에서 통과** |
| Tact | tact = b0 + a·bump + b·bump·(F/64) | R²≈0.33 (예비 — 예측변수 보강 필요) |

## 2차 모델링 계획 — void 정확도 + R극단 안정화

### 2차 배경
**현황**: 기존 38런에서 void 발견(644건) — 그러나 **100% kV62 아티팩트** (같은 bump가 kV60·58에선 0.00%). 웨이퍼 자체는 void-free.
- **False NG(거짓 불량)**: 기존 데이터로 완전히 설명 가능 → 안전 운영점 = kV60·R0.5 = void 0%
- **False OK(진정한 void 미검출)**: void 샘플 없어 미검증 → 별도 실험 필요
- **R×F 미검증**: R=0.35·F32만 한 건 테스트 → F↑로 안정화 여부 불명

### 2차 실험 설계 — 3개 Phase

| Phase | 대상 | 조건 | 신규 런 | 목표 |
|---|---|---|---|---|
| **B1: R×F** (우선) | 26µm | kV60·R0.35·F{32,64,128,256}×2반복 | 8 | R극단에서 F↑ → 측정 안정화? → R하한 재정의 가능성 |
| **B2: kV×F** | 26µm | kV59.5·R0.5·F{32,128} | 3 | 포물선 마진(±1kV)에서 F 불필요 확인 |
| **C: False OK** | void 자재* | kV{60,62}·R{0.5,0.35,1.5} | 7~10 | 8% 판정선에서 진정한 void 검출률(sensitivity) 측정 → False OK 위험 정량화 |

\* void 자재 조건: PD 거의 무관(26/86 상관없음), **8% 이상 void 함유**한 웨이퍼 필요

### 2차 실행 로드맵

**1단계 (즉시, 1~2주):** Phase B1 시작
- 26µm·kV60·R0.35·F{32,64,128,256}
- Q_dia, N8, 측정 성공률(FailedToMatchCAD) 기록
- **결과 1**: Q/N8 F무관 → F32 최소화 정당화 / **결과 2**: 측정 한계 발견 → R하한 또는 F하한 상향

**2단계 (1개월):** Phase B2 진행
- 26µm·kV59.5·R0.5·F{32,128}
- **목표**: 마진 kV에서도 포물선이 완만 확인 → kV 트림 마진 넓음

**3단계 (void 샘플 확보 후):** Phase C 실행
- void 자재로 좋은점(kV60) vs 나쁜점(kV62/극단R)
- **목표**: 안전 운영점 검증 + False OK 확률 추정

### 현재 결론 (Phase A+B1·B2 기반, 1차 완결)
- **직경 정확도**: kV≈60 고정 후 ±1kV 트림. R/F/W는 직경 무영향 → F32·W4 고정 타당
- **False NG**: 기존 데이터로 완전히 설명(kV62 아티팩트) → 안전 운영점 = kV60·R0.5·F32·W4
- **False OK**: 미검증이지만, 웨이퍼 void-free이고 좋은 운영점이 1차 직경 최적조건과 일치 → 위험성 낮을 것으로 추론
- **R극단 안정화**: B1(R0.35·F높음) 결과 기다리는 중 → 성공하면 26µm 해상도 2배 개선

## 한계 (실측 기반, 2차 모델링 진행 중)
