# 공정 모델링 (하이브리드: Python 엔진 + Excel 계산기)

DOE 38런(`../실험데이터/`) 실측을 회귀해 **PD 직경 → 추천 kV/R/F/W** 모델을 만듭니다.

## 구조
```
공정모델링/
├── pipeline.py            ← 엔진(Python): CSV 취합 → 회귀 → 계수·뷰·계산기 생성
├── 레시피_계산기.xlsx      ← 산출물(Excel): 오퍼레이터 front-end (PD 입력→추천)
│    · 시트: 레시피_계산기 / 파라미터_메커니즘 / 오차기준_근거 / 모델계수
├── outputs/
│   ├── run_level_summary.csv    런별 요약(Q_dia·N8·게이트·tact·bump수)
│   ├── bump_level_merged.csv    bump별 결과 + DOE 조건(회귀/분석 원천)
│   ├── model_coefficients.json  직경(kV²)·kV*(D)·tact 계수
│   └── views/                   직경Gate·N8·tact·DOE주효과 그림(PNG)
└── README.md
```

## 실행
```bash
cd 공정모델링 && python3 pipeline.py
```
새 런이 추가되면(예: 3-anchor 57런) 엑셀만 채우고 **재실행 한 번**이면 계수·계산기가 갱신됩니다.

## 파라미터 메커니즘 — 직경 D가 주어지면 각 값을 어떻게 정하나

각 파라미터는 **서로 다른 오차원(error source)** 을 담당합니다. 모델은 D가 주어지면 각각을 자기 목표에 맞춥니다.

| 파라미터 | 무엇을 조절(물리) | D가 주어지면 | D 의존성 |
|---|---|---|---|
| **kV** | X-ray 투과·대비 → threshold가 잡는 범프 경계 위치 → **측정직경** | 측정직경=PD 되는 **포물선 정점(≈60)** 에 고정 후 ±1kV 트림. **정확도** 담당 | 거의 무관(26·86µm 둘다 ~60) |
| **R** | 픽셀 크기 → 8% void가 몇 픽셀(N8)로 표현되나 → **픽셀화 오차(2/N8)** | N8 게이트 되는 **가장 거친(빠른) R = D·√0.08/N8**. **해상도** 담당 | D에 비례(클수록 R↑ 가능) |
| **F** | 여러 장 평균 → **랜덤 광자노이즈** 저감(∝1/√F). 측정직경·N8은 불변 | 노이즈 σ가 예산 안에 드는 **최소 F(≥32)**. **재현성** 담당 | 무관(조건별 σ로 결정) |
| **W** | X-ray 선속(밝기) → 광자부족 영역 SNR. **시간은 안 늘어남** | 얇은 범프는 4 고정. 두꺼운 범프 내부가 어두울 때만 ↑. **밝기** 담당 | 두께 의존(현재 자재는 4) |

**한 줄 요약**: `kV=정확도, R=해상도, F=재현성, W=밝기`. 네 오차원이 독립이라 각각 따로 목표에 맞춥니다.
- kV는 **직경 정확도**만 담당(±2kV에 8%/kV로 급변, 그래서 정점 고정).
- R은 **void 해상도**만 담당(작을수록 픽셀↑ 정밀하지만 광자부족으로 측정 붕괴 위험 → 하한 존재).
- F·W는 **직경·N8을 못 바꾸고** 노이즈·밝기만 손댐. 단 광자부족으로 측정이 실패하는 걸 막아 **측정 성립 여부**에는 관여.

## 오차 기준 ε = 20% (자재 무관 통일)

- **근거 이론**: 게이지 R&R(측정시스템분석, AIAG MSA / ISO 14253) — 측정오차 ≤ 판정공차의 **10%=우수, 10~30%=허용, >30%=불가**.
- **왜 20%**: 8% void 판정선에 적용. **10%(우수)는 86µm만 통과**하고 26·10µm은 구조적 탈락. 같은 이론의 **'허용' 등급 범위(10~30%) 안에서 통일값 20%** 를 채택 → 자재마다 기준을 바꾸지 않고 동일 원칙 적용.
- **총오차 구성**: `총오차 = √(픽셀화² + 노이즈²)`. 픽셀화=2/N8(R로 결정, 계통), 노이즈=2σ(F/W로 결정, 랜덤).
- **N8 게이트 유도**: 픽셀화·노이즈 균등분할 → 각 ≤ ε/√2 ≈ 14.1% → 픽셀화 2/N8 ≤ 14.1% → **N8 ≥ 2√2/ε = 14**. (ε=10%였다면 29)
- **효과**: N8≥14로 완화하니 86µm(여유)·**26µm(R≤0.5, N8≈14.7 통과)**·10µm(R≈0.2에서 N8≈14, 측정 성공 시)까지 달성 가능.

> ※ 10µm은 실측 없이 외삽. 26µm의 R=0.35는 **F=32에서 확인된 적이 없음**(데이터엔 F=128 조합만 존재) — F=32 기준 실측확인 R하한은 0.5, 그보다 낮추려면 Phase B1(R×F) 확인 필요.

## 모델 요약 (현재 38런 기준)
| 모델 | 형태 | 결과 |
|------|------|------|
| 직경 | ln_Q = b0 + b_kV·kV + b_kV2·kV² + b_R·R + b_F·F + b_W·W (anchor별) | **kV–직경은 포물선**, kV*≈60(D 거의 무관), R²=0.93(26µm)/0.96(86µm) |
| kV*(D) | 2 anchor 직선 | kV*(D) ≈ 60 |
| N8 게이트 | N8 = 측정직경·√0.08 / R ≥ **14** (ε=20%) | 통과 27/38, 직경+N8 동시 17/38. **26µm도 R≤0.5에서 통과** |
| Tact | tact = b0 + a·bump + b·bump·(F/64) | R²≈0.33 (예비 — 예측변수 보강 필요) |

## 2차 모델링 계획 — void 정확도 + R극단 안정화

### 왜 회귀 모델만으로 교호작용까지 다 안 잡히나

**회귀식이 additive(kV+R+F+W를 각각 더하는 형태)라서, 데이터에 없는 조합의 교호작용은 원리상 추정 불가능합니다.** R×F 교호작용을 예로 들면: 기존 38런에서 **R=0.35는 F=128로만, R=0.65는 F=32(또는 64)로만** 테스트됐습니다 — R을 바꿀 때마다 F도 같이 바뀌어서, "Q가 변한 게 R 때문인지 F 때문인지"를 통계적으로 분리할 수 없는 상태(교락, confounding)입니다. 아무리 좋은 회귀 알고리즘도 **데이터에 없는 정보를 만들어낼 수는 없어서**, 이런 조합은 실측으로 빈칸을 채워야만 회귀식에 교호작용 항(R×F 등)을 넣을 수 있습니다. 즉 "모델을 더 잘 만들면 해결되는 문제"가 아니라 **DOE 설계 자체의 구멍**이라, 추가 실험 없이는 못 메웁니다.

### 교호작용 전수 판정 (`2차_void정확도_DOE.xlsx` → `교호작용_현황` 시트)

| 교호작용 | 대상 | 상태 |
|---|---|---|
| **kV×R** | 거짓void | ✅ 검증됨(있음) — kV62+R극단(0.35·0.65)만 거짓NG 8~10%, 같은 kV62라도 R0.5는 0% |
| kV×R | 직경 | ✅ 검증됨(불필요) — R 주효과 자체가 Δ≤2.1%p로 미미 |
| **kV×F** | 거짓void | ✅ 검증됨(없음) — kV62·R0.5에서 F32/64/128 전부 거짓NG 0% |
| **kV×W** | 거짓void | ✅ 검증됨(없음) — kV62·R0.5에서 W4/6 전부 거짓NG 0% |
| **R×F** | 직경+거짓void | 🔶 미검증→해소 예정 — R0.35=F128뿐, R0.65=F32/64뿐(교락) → PhaseB-RF 4런으로 해소 |
| R×W | 직경+거짓void | ⏸ 미검증(보류) — 마찬가지로 교락, 다만 W 주효과가 F보다도 작아 우선순위 낮음 |
| F×W | 직경+거짓void | ➖ 확인불가(무의미) — 안전구간에서만 조합돼 반응이 전부 0이라 상호작용을 정의할 변동 자체가 없음 |
| kV×자재(D) | 직경 | ✅ 검증됨 — 2anchor 각각 kV*≈60, 자재 무관 |
| R×자재(D) | 직경+거짓void | ✅ 검증됨(정의 관계) — R=D·√0.08/N8_MIN 자체가 D 의존 공식 |

### 2차 실험 설계 — 통합판 (Phase B1을 PhaseB에 흡수)

| Phase | 대상 | 조건 | 신규 런 | 목표 |
|---|---|---|---|---|
| **PhaseB (경계매핑+R×F 해소)** | 26µm | kV{60,61,62}×R{0.4,0.5,0.6} 9런 + 운영점(kV60,R0.5) 반복 3런 + **R×F 교락 해소 4런**(RF1~4: kV{60,62}×R{0.35,0.65}에서 빠진 F 조합) | **16** | 거짓NG 안전창 경계 확인 + R×F 교호작용을 직경·거짓NG 양쪽에서 동시 해소 |
| B2: kV×F 가드 (낮은 우선순위) | 26µm | kV59.5·R0.5·F{32,128} | 3 | 포물선 저kV쪽 마진에서도 F 무관한지(고kV쪽은 이미 확인됨 — 대칭성 확인 차원, 필수는 아님) |
| **PhaseC: False OK** | void 자재* | kV{60,62}·R{0.5,0.35,1.5} | 7~10 | 8% 판정선에서 진정한 void 검출률(sensitivity) 측정 → False OK 위험 정량화 |

\* void 자재 조건: PD 거의 무관(26/86 상관없음), **8% 이상 void 함유**한 웨이퍼 필요

이전엔 직경용 Phase B1(8런)과 거짓void용 PhaseB(12런)를 따로 설계했는데, 둘 다 "R=0.35/0.65에서 F를 바꿔보면?"이라는 같은 실험이 필요했던 것이라 **RF1~4 4런으로 통합**했습니다(kV60 짝=직경 Phase B1 답, kV62 짝=거짓NG PhaseA 교락 해소 답). 기존 20런 계획 → **16런**으로 축소.

### 2차 실행 로드맵

**1단계 (즉시, 2~3주):** PhaseB 16런
- 경계매핑 9런 + 운영점 반복 3런 + R×F 해소 4런(RF1~4)
- 기록 항목: 거짓NG율%, Q_dia, (RF1~4는 N8도)
- **결과**: 거짓void 안전창의 정확한 경계 + R×F 교호작용 유무(직경·거짓NG 동시) 확정

**2단계 (선택, 1개월):** B2 — 우선순위 낮음
- kV62쪽에서 이미 kV×F 무관이 확인됐으므로, kV59.5(반대쪽)도 확인할지는 선택
- 스킵해도 1단계 결론에 영향 없음(대칭성 가정이 강함)

**3단계 (void 샘플 확보 후):** PhaseC 실행
- void 자재로 좋은점(kV60) vs 나쁜점(kV62/극단R)
- **목표**: 안전 운영점 검증 + False OK 확률 추정

### 현재 결론 (Phase A + 교호작용 전수판정 기반, 1차 완결)
- **직경 정확도**: kV≈60 고정 후 ±1kV 트림. R/F/W는 직경 무영향 → F32·W4 고정 타당
- **False NG**: kV×R 교호작용으로 완전히 설명(kV62+R극단 조합만 위험) → 안전 운영점 = kV60·R0.5·F32·W4
- **kV×F, kV×W**: 상호작용 없음 확정(위험지점에서도 F/W 무관하게 0%)
- **False OK**: 미검증이지만, 웨이퍼 void-free이고 좋은 운영점이 1차 직경 최적조건과 일치 → 위험성 낮을 것으로 추론
- **R×F**: 원본 DOE 교락으로 미검증 → PhaseB-RF 4런으로 해소 예정(직경·거짓NG 동시)

## 한계 (실측 기반, 2차 모델링 진행 중)
- **PhaseB 미완**: 거짓NG 경계 정밀 위치 + R×F 교호작용 유무 미확인 → 진행 예정
- **R×W 미검증**: 우선순위 낮음(F보다 주효과 작음)으로 보류
- **PhaseC 미완**: False OK 미검증 — void 샘플 확보 필수 → 보류
- **Tact 모델 예비**: R²≈0.33, 타일수/셋업시간 등 추가 변수 필요
