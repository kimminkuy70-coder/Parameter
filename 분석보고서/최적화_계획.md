## 1. 목표

**X-ray 장비(Nordson XM8000)의 검사시간을 단축하면서, "적당한" 검사품질을 유지한다.**

시간 구조(실측+SOP):
- **Image Acquisition(WS 초기 스캔) ≈ 30분** (SOP 슬라이드7 "대략 30분 소요") ← **시간의 대부분**
- Analysis 검사(선택 die) ≈ die당 93~102초 × 5~6 die ≈ **10분 내외** (RUN 세트 타임스탬프 실측)

**[재추론]** 기존 문서(SOP_VARIABLES)는 "Frame Average가 1순위 시간 변수"라고만 했으나,
시간의 지배 항이 Acquisition이므로 전략이 달라진다:
> **Acquisition은 싸게(품질은 '검출만 되면' 충분), Analysis는 시간 여유가 있으므로 품질에 투자.**
> 두 단계는 목적이 다르다 — Acquisition=CAD 정렬용 검출, Analysis=void 정량.

## 3. 검사시간 단축 방안 (우선순위)

**[재추론] 절감 효과 = (그 단계의 시간 비중) × (그 단계에서 줄인 비율)** 이므로:

1. **Acquisition Frame 64→32** : 취득시간 ≈ 절반. 검출용이라 품질 영향 없음(사용자 32 검증).
   → 전체의 최대 절감. **[즉시 적용 가능]**
2. **Acquisition R 0.8→1.0~1.5** : 타일수 1/R²로 감소(0.8→1.2만 돼도 취득 ~2.3배 빨라짐).
   단, CAD 매칭이 유지되는 상한을 실험으로 확인 필요(§6-실험3).
3. **Analysis R을 "필요한 만큼만" 거칠게** : R=D·√p/N (§5). 특히 **큰 범프에서 낭비 심함**
   (80µm에 R0.6 → 14배, 182µm에 R1.0 → 26배 여유 — DIAMETER/PARAMETER_MODEL 검증).
4. **Analysis Frame은 유지(64)** : 검사부는 짧아서 줄여봐야 전체 이득이 작고, 품질(재현성)만 손해.
   **[재추론] "시간은 Acquisition에서 벌고, 품질은 Analysis에서 지킨다"**
5. 샘플링(Die/AOI 축소)은 대표성 리스크가 있으므로 마지막 수단.

> 개산: Acq 30분→(Frame 절반, R 0.8→1.2) ≈ 30×0.5×0.44 ≈ **7분**. Analysis 10분 유지 시
> **전체 40분 → 17분 수준 (~2.4배)**, Analysis 품질은 그대로.

## 4. "적당한 품질"의 정의 (정량)

**1차 KPI — 측정 범프직경의 정확도** (사용자 정의 채택):
```
Q_dia = 측정 직경(XRA_VOID Diameter 중앙값) / nominal(도면·이미지명 BumpSize)
합격:  0.90 ≤ Q_dia ≤ 1.05     (목표 0.97~1.03)
```
근거(데이터): 정상 레시피는 92~102%에 분포(RUN 92~93%, NXP 100%, QORVO 102%),
이상 셋업은 34~46%(TEST)·39~67%(182µm 예외)로 명확히 구분됨 → 0.90 경계가 두 군을 가름.

**2차 KPI**: 선택 die **CAD 매칭 100%** (Composite only).
**3차 KPI**: void% 재현성 — 동일 웨이퍼 반복측정 시 8% 경계 판정이 뒤집히지 않을 것
(σ_void ≤ ε·8%, ε는 §5의 N과 연동).

## 5. 현 데이터로 아는 것 + 파라미터 계산 모델

### 데이터로 확정된 사실 (근거 문서)
| 사실 | 근거 |
|------|------|
| kV 창은 60kV 중심 ±2.5kV로 매우 좁음 (55/65 전멸) | RUN_CONDITIONS |
| 고정 60kV는 80µm에만 맞음 (20µm 전멸, 182µm 부분) | merged_results/ANALYSIS |
| Power 3.5~4.5W는 화질·시간에 무영향 | PARAMETER_MODEL §2 |
| R 과잉(미세)은 시간 낭비 + 과소측정 유발 | DIAMETER_COMPARISON |
| 정상 셋업은 Q_dia 92~102% | DIAMETER_COMPARISON |
| Acquisition Frame 32로도 검사 성립 | 사용자 검증 |

### 계산 모델 (상세 유도는 파라미터_모델.md, 계산기는 ../계산모델_엑셀/파라미터_계산기.xlsx)
```
[공통 입력] 범프직경 D, 두께 d, void임계 p, 허용오차 ε, 재질 보정점(d0,V0,n)

kV      = V0·(d/d0)^(1/n)  (첫추정, n≈3)  → 확정: Q_dia≈1 될 때까지 1kV 미세조정 (폐루프)
Power   = 4W 고정
N       = 2/ε                              (void당 최소픽셀)
R_ana   = D·√p / N                          (Analysis 해상도 — void 정량 기준)
R_acq   = D / N_detect                      (Acquisition 해상도 — 검출 기준) [재추론·신규]
          N_detect = 범프 검출·정렬에 필요한 범프당 픽셀 (≈10~26 추정, §6-실험3으로 확정)
Frame_acq = 검출 성립 최소값 (32 검증됨, 16 시도 여지)
Frame_ana = 재현성 기준 (64 유지 — 시간 여유 있음)
```
**[재추론·신규]** R을 하나로 취급하던 기존 모델을 **R_acq(검출용)와 R_ana(정량용)로 분리**.
근거: RUN에서 R=1.0(범프당 ~26px→실측 15.7px)으로 매칭·정확 측정 모두 성립 →
N_detect 상한은 26px 이하에 존재. 하한(어디까지 거칠어도 되나)은 미확정 → 실험 필요.

## 6. 부족한 부분을 채우는 새 실험 (공정모델링 동시 진행)

### 미확정 항목 → 실험 매핑
| 미확정 | 채우는 실험 |
|--------|-------------|
| kV 지수 n (재질별) | 실험1 |
| kV 창의 폭(±몇 kV) | 실험1 |
| N (void당 최소픽셀) | 실험2 |
| N_detect (Acquisition 검출 한계) | 실험3 |
| Analysis Frame 하한(재현성) | 실험4 |

### 공정모델링 변수 설계 [추천]
- **절대변수(재질 종속 — 재질마다 보정)**: kV(또는 목표투과율 T*), 재질(ρ·Z·적층), 범프 두께 d
- **상대변수(무차원 — 재질·크기 이관 가능)**: 
  - `N = D√p/R_ana` (void당 픽셀) ← 품질을 크기와 무관하게 표현
  - `N_detect = D/R_acq` (범프당 픽셀)
  - `d/d0` (두께비) ← kV 스케일링 입력
  - Frame 수, Q_dia(응답)
- 이렇게 잡으면 **모델이 "26µm에서 R=1.0" 같은 절대값이 아니라 "void당 7px" 같은
  무차원 규칙으로 학습**되어, 새 자재에 크기만 넣으면 이관된다. (목표 부합: 시행착오 최소화)

### 실험 계획 (모두 동일 양품 웨이퍼, 응답변수 = Q_dia · 매칭률 · void% · tact)

**실험1 — kV 미세 스윕 (최우선, 공정모델의 절대변수 보정)**
- 고정: R_ana(계산값), Frame 64/32, Power 4W. 변화: **kV 57~63, 1kV 간격** (7런)
- 산출: 창 중심·폭, Q_dia(kV) 곡선. **다른 크기 범프 1종 추가 시 n까지 fit** (총 14런)
- 판정: Q_dia 0.97~1.03 구간 = 창

**실험2 — Analysis R 스윕 (상대변수 N 확정)**
- 고정: kV(실험1 결과), Frame 64. 변화: **R_ana 0.4/0.6/0.8/1.0/1.3/1.6** (6런)
- 산출: void%와 Q_dia가 안정→붕괴되는 지점 = **경험적 N** (N=2/ε 이론치와 대조)
- 실제 void 있는 die(예: TEST5에서 void 검출된 위치) 포함할 것

**실험3 — Acquisition 절감 한계 (시간 최대 절감원)**
- 고정: Analysis 전부. 변화: **Acq Frame 32/16 × Acq R 0.8/1.2/1.6** (6런)
- 판정: CAD 매칭 100% 유지되는 최소 조합 → **N_detect 확정**
- 산출: 취득시간 실측 → §3 개산 검증

**실험4 — Analysis Frame 재현성 (품질 마진 확인)**
- 고정: 나머지 전부. 변화: **Frame 64/32, 각 3회 반복** (6런)
- 산출: void%·Q_dia의 반복 σ → Frame 하한. (예상: 64 유지 결론이나, 32로도 σ 충분하면 추가 절감)

**총 ≈ 33런.** 실행 순서 1→3→2→4 (시간 절감 효과 큰 것 먼저 확정).
각 런 채점은 자동화 가능(측정직경/nominal, 매칭률 — 기존 분석 스크립트 재사용).

### 종료 조건
모든 크기 구간(소/중/대)에서: Q_dia 0.90~1.05 + 매칭 100% + void 재현 + tact ≤ 목표(예: 현 40분→20분).
결과는 파라미터_모델.md·엑셀 계산기의 보정값(n, N, N_detect)으로 반영해 모델 완성.
