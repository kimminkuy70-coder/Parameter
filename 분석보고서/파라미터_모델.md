# X-ray Void 검사 파라미터 계산 모델 (Nordson XM8000)

범프 X-ray void 검사에서 **kV / Power / Resolution(R) / Frame Average / void당 픽셀수 N**을
범프 스펙(직경·두께·재질)과 void 판정기준(%)으로부터 산출하기 위한 계산식과 배경지식 정리.

> 표기: 데이터로 검증됨 ✅ / 물리이론 기반(보정 필요) ⚠️ / 데이터 fit 불가(정성) ▶

---

## 0. 배경지식 — X-ray 투과 이미징 기본식

**감쇠(Beer–Lambert) 법칙**
```
T = I / I0 = exp( − μ_m · ρ · d )
```
- T: 투과율(검출기 도달 비율), μ_m: 질량감쇠계수[cm²/g], ρ: 밀도[g/cm³], d: 통과 경로길이[cm]
- 범프(솔더 볼/필라)에서 d ≈ 범프 두께(투과 경로). ρ·d = 면적밀도(mass thickness).

**에너지 의존성**
- μ_m 은 광자에너지 E에 의존. 20~80 keV 대역에서 고밀도 금속(Cu·Sn·Ag)은 광전효과 지배 →
  `μ_m ∝ Z^(4~5) · E^(−3)` (대략). 즉 **에너지 높을수록 덜 흡수**.
- 튜브 전압 V(kV)와 유효에너지: `E_eff ≈ 0.5~0.6 × V`. 실무적으로 `μ_m ∝ V^(−n)`, **n ≈ 2.5~3.5**.

**신호대잡음(SNR) — 광자 제한**
- 검출 광자수 N_ph 에 대해 `SNR ∝ √N_ph`, void 검출은 `CNR = C·√N_ph` (C=void 대비).
- `N_ph ∝ Φ · t · N_frame · T · A_pixel`, Φ=선속(∝Power), A_pixel ∝ R².

---

## 1. Voltage (kV) — 침투/대비 결정 ⚠️

**원리**: 최적 kV는 범프 중심 투과율을 "포화(너무 검음)도 세척(너무 옅음)도 아닌" 목표 T\*로 맞추는 값.
`μ_m(V)·ρ·d = −ln(T*) = 상수` 로 두고 `μ_m ∝ V^(−n)` 대입 →

```
V_opt = V0 · ( d / d0 )^(1/n)          (같은 재질)
        n ≈ 3 (시작값), 재질별 2.5~3.5
```
- V0, d0 = 이미 잘 되는 기준점(예: 이 재질 80µm → 60kV), d = 새 범프 두께.
- **두께의 약 세제곱근**으로 완만히 증가. → 값 변화는 작지만(민감), 크기가 크게 다르면 최적점이 이동.

**실험적 근거 (TB500M, 26µm)** ✅
- 55kV 전멸 / 60kV 통과 / 65kV 전멸 → **통과 창 ±2.5kV**로 매우 좁음.
- → kV는 **1kV 단위 미세 스윕**으로 창을 찾아야 함. 너무 낮으면 중심 포화, 너무 높으면 대비 소실.

**한계**: 상수(V0)와 지수 n은 **재질(ρ, Z)마다 다름**. 서로 다른 제품(TB500M vs NXP 등)은 하나의 식으로 못 묶음 → 재질별 보정 필요.

**실무 마스터 규칙(폐루프, 재질·크기 무관)** ✅ 추천
```
측정 범프직경 ≈ nominal(도면값) 이 될 때까지 kV를 미세조정
```
- nominal은 이미지명 `BumpSize_XXum` / 도면값. 측정직경은 XRA_VOID `Diameter(um)`.
- 물리상수 몰라도 자기보정됨. (검증: RUN 26µm→24µm=92% 정상 / TEST R=0.2는 과소측정 이상)

## 2. Power (W) — 선속/SNR/속도 (침투 아님) ▶

**원리**: 고정 kV에서 Power ∝ 튜브전류 ∝ **선속(photons/sec)**. 침투(kV)와 별개.
CNR 일정 유지 조건:
```
Power · t_frame · N_frame · T · R²  =  일정
→ Power ∝ 1 / ( N_frame · T · R² )   (광자 제한일 때)
```
즉 이론상 **두꺼운 범프(T↓)·미세 R(R²↓)일수록 더 큰 Power(또는 더 많은 Frame) 필요**.

**실험적 근거 (TB500M)** ✅ — 실제로는 거의 무효과
- 60kV 고정, 3.5/4.0/4.5W: **배경밝기·노이즈·대비·이미지 전부 동일**, tact도 차이 미미.
- NXP 3개 레시피(20/80/182µm)도 모두 Power ~4W로 **고정** → 크기별 power 변화 실험 자체가 없음.

**해석**: 이 장비는 배경을 흰색(≈254)으로 **자동노출 정규화 + Frame 64 평균**. 그래서 사용범위(3.5~4.5W)에선
광자가 충분(포화)해 **Power를 올려도 화질 불변, 사실상 속도(throughput) 변수**로만 작동.
- Power가 화질에 관여하는 경우: **매우 미세 R + 매우 두꺼운 범프**로 광자 부족(시간 상한)일 때만.
- 과도한 Power → 초점 스팟 확대 → **경계 흐림/포화 위험**(상한 존재).

**결론(데이터 fit 불가, 정성)**:
```
Power = 중간값 고정(예 4W).  SNR 부족은 Power보다 Frame Average로 해결.
크기별 계산식에 넣는 주요 변수 아님. (throughput/스팟크기 보조 knob)
```

## 3. Resolution R (µm/pixel) — void 측정 정밀도 ✅ (검증됨)

**원리**: void 판정에 필요한 최소 픽셀을 확보하는 가장 거친(=빠른) R.
void 면적이 범프의 p(%)면 → void 지름 `d_void = D_bump·√p`. 이를 N픽셀로 담으려면:
```
R_max = D_bump · √p / N          (R ≤ R_max 사용)
```
- D_bump=범프직경, p=void 면적 임계(예 0.08), N=void당 최소 픽셀(§4).

**검증 (님 데이터, p=5~8%, N=8 가정)** ✅
| 범프 | 실제 R | void 픽셀 | N=8 허용 R | 가능 배속(∝1/R²) |
|------|--------|-----------|-----------|-------------------|
| 20µm | 0.6 | 7px | 0.56 | ~1x (적정) |
| 80µm | 0.6 | 30px | 2.24 | ~14x |
| 182µm | 1.0 | 41px | 5.09 | ~26x |
| 26µm RUN | 1.0 | 7px | 0.92 | ~1x (적정) ✅ |
| 26µm TEST | 0.2 | 37px | 0.92 | ~21x (과잉) |

→ **큰 범프는 필요보다 R을 과도하게 미세하게 써 시간 낭비**. RUN(26µm,R=1)은 void당 ~7px로 적정.

**추가**: 미세 R은 오히려 **경계 그라데이션을 해상해 threshold가 중심만 잡음 → 과소측정 + 매칭 실패**(TEST 세트 사례). "해상도 높음 ≠ 검사 좋음".

## 4. N (void당 최소 픽셀) — R 공식의 핵심 상수 ⚠️

**주의**: "N=6~10"은 확정 표준이 아니라 rule-of-thumb였음. 실제 근거는 아래.

**원리**: void **면적** 측정오차는
1. **경계 이산화(threshold 편향)**: 지름 D픽셀 원의 상대 면적오차 ≈ `2/D` (경계가 ~0.5px 치우칠 때)
   - D=10px → ~20%, D=20px → ~10%, D=40px → ~5%
2. **노이즈**: 무작위라 픽셀 많을수록 ~1/√D로 상쇄.

**N 결정식(정확도 목표에서 역산)**:
```
N ≥ 2 / ε          (ε = 허용 void% 상대오차)
  ε=0.10 → N≈20,  ε=0.05 → N≈40,  검출만 → N≈5
```

**권장 확정법(우선순위)**:
1. **경험적**(추천): 실제 void 하나를 여러 R로 측정 → void%가 안정화되는 지점 직전이 최소 N.
2. **정확도 역산**: 위 `N≈2/ε`.
3. **벤더 스펙/엔지니어**: 장비 void 알고리즘의 "void당 최소 픽셀" 사양 확인(엔지니어 질문 Q2와 동일).

---

## 5. Frame Average — SNR/tact ▶
- 노이즈 저감 knob. `SNR ∝ √N_frame`. 두꺼운 범프(T↓)로 어두워 CNR 부족하면 ↑.
- tact와 정비례(대략 2배 = 시간 2배). 품질 하한 만족하는 **최소값** 선택.
- 두꺼운 범프의 SNR 부족은 Power보다 **Frame Average**로 잡는 게 맞음(§2).

---

## 6. 종합 산출 절차 (레시피 계산)

```
입력: 범프직경 D, 두께 d, void임계 p, 정확도 ε, 재질 보정점(d0,V0,n)

1) N   = 2/ε                       (또는 경험적 확정)
2) R   = D·√p / N                  (계산 확정 ✅)
3) kV  = V0·(d/d0)^(1/n)           (첫 추정, n=3 ⚠️)
      → 실제 확정: 측정직경=nominal(±3%) & 전 die 매칭 될 때까지 kV 1kV 미세스윕
4) Power = 중간값 고정(~4W)         (속도/스팟 보조 ▶)
5) Frame = 품질 하한 만족 최소값     (SNR knob)

품질 판정(자가검증): 측정직경/nominal ≈ 100% + 전 die Composite + void 재현
```

## 7. 한계 / 다음 단계
- **kV의 절대값·지수 n·Power**는 재질마다 다르고 현재 데이터로 확정 불가 → **재질별 kV 미세스윕 DOE**로 보정.
- **N**은 정확도 요구/노이즈에 따라 달라짐 → 경험적 측정 또는 엔지니어 사양 필요.
- R 공식은 데이터로 검증됨 → **큰 범프에서 R을 키워 대폭 속도 향상 가능**(정확도 N 확정 후).
