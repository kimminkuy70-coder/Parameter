# 레시피 모델링 마스터 실험계획서 (v4 — MINIMAL_DOE 대체)

보유 자재: **26µm (TB500M, void 실존 웨이퍼 보유)** / **158µm (repo 데이터 0건 — 신규)**
반영 사항: 오퍼레이터는 취득 생략 후 기존 레시피로 검사 → 기존 양산 매칭률은 CAD 신선도와 교란됨.

---

## 1. 목표와 목적

**목표(Goal)**: 가장 적은 검사시간으로 "적당한" 검사품질을 유지하는 **레시피 파라미터 생성기**를 만든다.
- 최종 산출물 = 자재 정보(die 사이즈, bump 사이즈)만 입력하면 파라미터를 제시하는 엑셀(§6).

**목적(Objectives)** — 실험으로 확정해야 할 것:
| # | 목적 | 왜 실험이 필요한가 |
|---|------|---------------------|
| O1 | 자재별 최적 kV와 kV→품질 기울기 확정 | 26µm는 외삽값(57.2) 미검증, 158µm는 데이터 0 |
| O2 | void 정확도에 필요한 최소 픽셀 N 실측 | 현재 이론값(2/N)뿐 — 실측 없음 |
| O3 | 픽셀 수→매칭 성공의 인과 확정 | 기존 데이터는 CAD 신선도와 교란되어 미확정 |
| O4 | Frame→품질(재현성)·시간 곡선 확정 | inspection Frame 효과 데이터 0 |
| O5 | 취득 생략(CAD 재사용) 페널티 정량화 | 양산 실태 반영 — 데이터 0 |
| O6 | 시간모델 tact(R,F) 계수 확정 | 부분적 타임스탬프만 존재 |

## 2. "적은 시간"과 "적당한 품질"의 수치화 + 메커니즘

### 2-1. 적은 시간 (최소화 대상)
| 지표 | 정의 | 지배 메커니즘 |
|------|------|----------------|
| **tact_insp (초/die)** | 검사 1 die 소요시간 (이미지 타임스탬프로 실측) | 타일수(∝die면적/R²) × Frame × 단위노출 + 이동 오버헤드 |
| tact_acq (분/웨이퍼) | 취득 시간 (셋업 리드타임) | 웨이퍼면적/R² × Frame (검사와 동일 구조) |

### 2-2. 적당한 품질 (제약 조건 — 이 값을 만족하는 한에서 시간 최소화)
| 지표 | 정의 | 합격 기준 | 메커니즘 |
|------|------|-----------|----------|
| **매칭률 M** | Composite die / 검사 die | **100%** | kV 창(대비) + 범프 픽셀수 + CAD 신선도 |
| **Q_dia** | 측정 범프직경 ÷ 도면 nominal | **0.97~1.03** (허용 0.90~1.05) | kV 다이얼(−3%p/kV, 26µm 실측) |
| **void% 정확도** | 기준값(최미세 R) 대비 편차 | **±ε (ε=10% 제안, QA 확정 필요)** | void당 픽셀 N: 오차≈2/N + Frame 노이즈 |
| void% 재현성 | 동일조건 반복 σ | 8% 경계 판정 불변 | Frame(SNR ∝√F) |

> **최적화 문제로 요약**: minimize tact(R,F) subject to M=100%, Q_dia∈[0.97,1.03], void오차≤ε.

## 3. 변수 정의

**독립변수(우리가 설정)**: kV, R(µm/px), Frame, CAD 신선도{신규취득, 재사용}, 자재{26, 158µm}
**고정변수(실험 안 함, 근거 있음)**: Power=4W(3.5~4.5 무효과 실측), 검사 die 수=5~6(십자), W·정렬값
**종속(응답)변수**: 매칭률 M, Q_dia, void%(및 기준 대비 편차), void% 반복 σ, tact_insp, tact_acq
**유도변수(모델 축)**: 범프픽셀 = D/R, void픽셀 N = D√p/R — 자재 무관 무차원 축으로 모델 이식성 확보

## 5. 모델링 파이프라인 (실험 → 공정모델 → 레시피모델)

```
[실험 데이터]
   ├→ 공정모델 (물리 관계식들의 계수 확정)
   │    ① Q_dia(kV) = 1 + s·(kV−kV*)          [A에서 s, kV* — 자재별]
   │    ② void%오차(N) 곡선 + N_target          [B에서 — 무차원, 자재 공통]
   │    ③ 매칭률(범프px, CAD신선도)              [B·P0에서]
   │    ④ void%σ(F)                            [F에서]
   │    ⑤ tact = a·(die면적/R²)·F + b           [전 런 회귀]
   └→ 레시피모델 (사용자 입력 → 파라미터 산출)
        입력: die 사이즈, bump 사이즈 D (+ void 판정 p)
        출력: R = D·√p / N_target (②)
              kV = 기준자재 kV* 보간 + Q_dia 트림 절차 (①)
              Frame = ④의 품질 하한 최소값
              취득 세트 = kV 공유, R·F 절약값 (③이 하한 보증)
              예상 tact = ⑤
```

## 6~8. 최종 산출물 사양 (실험 완료 후 제작; 골격은 선제작 가능)

**⑥ 레시피 모델링 엑셀** (`../계산모델_엑셀/레시피모델.xlsx`)
- 입력: die W/H, bump D, (p) → 출력: kV 시작값+트림절차, R, Frame, 취득세트, 예상 tact
- 각 파라미터의 의미·근거 설명 시트 + **글 SOP 시트**(취득→검사 절차, 사진은 PPT로 위임)

**⑦ 공정 모델링 엑셀** (`../계산모델_엑셀/공정모델.xlsx`)
- DOE 설계 근거(이 문서 §1~4), 런 결과 입력 시트(런시트 통합), 계수 자동 fit(기울기·N·F·tact)
- **시각자료**: kV-Q 직선, N-오차 곡선, px-매칭 곡선, tact 맵 차트 포함 — 사람이 DOE를 이해하도록

**⑧ SOP PPT 2종** (기존 SOP 양식 참고, 장비 화면 사진 포함)
- **오퍼레이터 버전**: 레시피 모델 엑셀에서 값 읽기 → 입력 → 검사 실행까지 최단 경로. 판단 없음.
- **Process Eng. 버전**: + 각 파라미터를 바꾸면 무엇이 변하는지(kV 다이얼, R/N, Frame/σ), 이상 시 조치 트리(Q_dia 어긋남→kV 트림, 매칭실패→창/CAD 확인)

> 산출물 의존성: ⑥⑦의 계수는 실험 결과로 채워짐 — 골격(수식·설명·차트 틀)은 지금 제작 가능, 
> 실험값이 들어오면 자동 완성되는 구조로 만든다.

## 부록 P — P0(취득 페널티)가 모델 구조를 결정하는 근거와 판정 규칙

**왜 P0가 갈림길인가**: 레시피 모델의 출력 항목이 P0 결과에 따라 달라진다.
- CAD 신선도가 1차 요인이면 → 모델 출력에 **"재취득 조건"** 항목이 필수로 추가되고,
  양산 절차(오퍼레이터 SOP)에 로트별 취득 단계가 들어가야 한다. 기존 양산 매칭률 데이터는 전부 재해석.
- 2차 요인이면 → 취득 생략 운용을 유지해도 되고, 매칭 모델은 kV·픽셀 2변수로 단순화된다.

**통제 설계**: 같은 웨이퍼, 같은 검사 파라미터(kV·R·F 동일), 같은 die 6개 — 변한 것은 CAD 신선도뿐.
따라서 매칭률 차이는 신선도 외의 원인을 가질 수 없다(웨이퍼·조건·픽셀 모두 동일).

**판정 규칙 (사전 등록 — 결과 보고 바꾸지 않기 위함)**:
| ΔM = M(신규취득) − M(재사용) | 판정 | 모델 조치 |
|------------------------------|------|-----------|
| **≥ 2 die (≥33%p)** | 신선도 = 1차 요인 | 모델에 CAD 신선도 입력 추가, 재취득 조건 정의, SOP에 취득 단계 복원 |
| **= 1 die** | 경계 — 판정 유보 | P1·P2 각 1회 반복 후 재판정 (합계 12 die 기준 ≥3 die 차이면 1차 요인) |
| **≤ 0 die** | 신선도 = 2차 요인 | 취득 생략 운용 유지, 매칭모델 = f(kV, 픽셀)로 단순화, merged 해석 복권 |

보조 지표: Q_dia 차이(정렬 어긋남은 직경 왜곡으로도 나타남), FailedToMatchCAD가 발생한 die의 위치
(가장자리 집중이면 정렬 원인 시사). 6 die 표본의 한계(이항 분포상 1 die 차이는 우연 가능)는
경계 규칙(반복 1회)으로 보완한다.

## 부록 W — Power(W) 최적화: 판정 지표 정의와 스윕 설계

### W-1. 문제 (SOP 원본 5페이지 증거)
같은 158µm 범프가 W만 바꿨는데 void%가 출렁인다: 4W → 227:0.2%, 251:0.3% / 5W → 227:0.1%, 251:0.0%.
**어느 쪽이 진짜인지 정답(ground truth)이 없다** — 그래서 "무엇을 보고 W를 조절할지"의 정의가 먼저다.

### W-2. 기존 "W 무효과" 결론의 정정 (맹점 규명)
- 이전 판정 근거는 배경·전역 통계였는데, **배경은 포화 상태(std 0.22)** — W 효과가 원리적으로 안 보이는 곳.
- W(선속)가 작동하는 곳은 **광자가 부족한 어두운 영역 = 범프 내부**다. 
- 얇은 26µm 범프는 내부도 충분히 밝아 W 둔감(실측 3.5/4.5W 내부 std 15.5 동일) →
  **W는 "두꺼운 범프(158µm급)의 내부 SNR" 전용 변수**로 재정의. 26µm는 4W 유지.

### W-3. 판정 지표 정의 (사전 등록 — 이걸 보고 W를 조절한다)
정답이 없어도 판정 가능한 성질: **진짜 void는 반복 측정에서 안정, 노이즈 void는 깜빡인다.**

| 순위 | 지표 | 정의 | 판정 |
|------|------|------|------|
| 1차 | **깜빡임 void 수** | 동일 조건 3반복에서 일부 반복에서만 검출되는 void 개수 (같은 범프 추적) | 0이 되는 최소 W |
| 1차 | **void% 재현 σ** | 같은 범프 void%의 3반복 표준편차 | σ ≤ ε·p (판정 경계 안정) |
| 2차 | **수렴(asymptote)** | void% vs W 곡선 — 최고 2개 W의 평균을 기준으로 ±ε 이내 | 수렴 시작점 = W_min |
| 가드1 | **경계 폭 (블러)** | 범프 edge의 명암 전이 폭(px) — W↑로 초점 스팟이 커지면 증가 | 4W 대비 +10% 되는 W = W_max |
| 가드2 | **Q_dia 불변** | W는 직경을 움직이면 안 됨 (움직이면 스팟 블러 신호) | 97~103% 유지 |

**운용 W 결정식**: `W_opt = min( 수렴 W_min 이상에서 여유 있게, W_max − 1단계 )`

### W-4. W·Frame 교환성 — 시간 절감의 숨은 기회
SNR ∝ √(W × F × t) 인데 **W는 시간 공짜, F는 시간 정비례**다.
→ 블러 한계(W_max) 안에서 W를 올리면 **같은 품질을 절반의 F(=절반의 시간)로** 얻을 수 있다.
검증 런: **(4W, F32) vs (8W, F16)** — void%·σ 동일하면 tact 절반 확보.
