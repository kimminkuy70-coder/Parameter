# 최소 실험 설계 v3 — 레시피 모델링 (취득 생략 교란 반영, 총 ~16런)

자재: **TB500M(26µm, void 웨이퍼 보유)** + **182µm 자재**. 
v2와의 차이: **운용 실태 반영** — 오퍼레이터는 Image Acquisition을 생략하고 기존 레시피로 바로 검사한다.
따라서 기존 양산 데이터(merged 362건)의 매칭률에는 **[취득 생략/오래된 CAD]라는 교란변수**가 섞여 있어,
"픽셀 수 vs 매칭" 등 기존 관찰을 확정할 수 없다. → 이 변수를 **Phase 0으로 분리 측정**한다.

## 0. 교란 구조 (왜 다시 짜는가)

```
매칭 성공  =  f( kV 적합성, 범프 픽셀 수(R), CAD 신선도(취득 여부·다른 로트) , 웨이퍼 상태 )
                                              ^^^^^^^^^^^^^^^^^^ 기존 데이터에서 통제 안 됨
```
- merged 362건: 취득 생략 + 레시피 제작 시점의 다른 웨이퍼 CAD → 매칭률(60%/34%/0%)의 원인 분리 불가
- TB500M RUN/TEST: 레시피를 직접 만들며 취득 수행 → 상대적으로 깨끗 (kV 결론의 주 근거는 유지)
- **미확정으로 강등된 결론**: "픽셀 수와 매칭은 무관" / "20µm 전멸 = kV 부적합" (CAD 노후 가능성 배제 불가)

## Phase 0 — 취득 생략 페널티 분리 (3런) ★신규·최우선

같은 웨이퍼·같은 검사 파라미터에서 **CAD 신선도만** 바꾼다.

| Run | 자재 | 조건 | 비교 대상 |
|-----|------|------|-----------|
| P1 | 182µm | 기존 레시피 그대로 (취득 생략 = 현행 운용) | — 현행 기준선 |
| P2 | 182µm | **신규 취득 후** 동일 검사 파라미터 | P1과 매칭률 차이 = **취득 생략 페널티** |
| P3 | TB500M | 기존 RUN 레시피 재사용 vs (Phase B의 신규 취득 결과와 비교) | 자재 2에서 재현 확인 |

**해석**: P2−P1 차이가 크면 → 양산 매칭률 저하의 주범은 취득 생략(로트별 취득 또는 정렬 보강 필요).
차이가 작으면 → merged 매칭률을 kV·픽셀 요인으로 해석 가능해짐(기존 분석 복권).

## Phase A — kV 확정 (신규 취득 상태에서, 2~3런)

| Run | 자재 | kV | R | F | 목적 |
|-----|------|----|----|---|------|
| A1 | TB500M | 57.5 | 1.0 | 32 | 예측 kV* 검증 (실패 시 58.5 백업) |
| A2 | 182µm | 62 | 1.0 | 32 | 기존 60kV 40건과 이어 기울기 확정 |

## Phase B — R 스윕 = N곡선 + "픽셀 vs 매칭" 통제실험 (7~8런)

TB500M void 웨이퍼, **신규 취득(절약세트: kV*, F32, R1.0)** 후 같은 die 고정.
kV는 B0에서 확정한 값으로 고정 → **R만 변하는 통제 조건**이 되어, v2의 N곡선 목적에 더해
**"범프 픽셀 수 → 매칭률" 인과를 처음으로 깨끗하게 측정**한다 (미확정 결론의 확정 실험).

| Run | R | 범프px | F | 목적 |
|-----|---|--------|---|------|
| B0 | 0.2 (kV 트림 1~2런) | 130 | 32 | Q≈100% 만들기 → 기준 void% |
| B1 | 0.6 | 43 | 32 | N곡선 + 매칭률 |
| B2 | 1.0 | 26 | 32 | 〃 (검증된 안전점) |
| B3 | 1.6 | 16 | 32 | 〃 — **26px 아래 첫 데이터** |
| B4 | 2.0 | 13 | 32 | 〃 — 취득 R 상한 후보 검증 |
| B5 | 1.0 반복 | 26 | 32 | 재현성 |
| B6 | 1.0 | 26 | **16** | Frame 하향 |
| B7 | 1.0 | 26 | **64** | Frame 상향 → F 16/32/32/64 4점 |

- 매 런 자동 기록: 매칭률, Q_dia, void%, tact → **매칭률(px) 곡선 + N곡선 + F곡선 + tact 모델** 동시 산출.
- B3·B4가 "픽셀 부족이 매칭을 깨는 지점"을 직접 찍는다 → 취득 R 상한도 여기서 확정.

## Phase C — 운용조건 검증 (2런)

| C2 | 182µm | 모델 산출 (kV*, R 완화, F32) + 절약 취득 | 〃 + tact 단축 입증 |

## 총계 & 순서

**~16런** = P 3 + A 2~3 + B 7~8 + C 2. 순서: **P1·P2 → A1·A2 → B → P3(B와 병합) → C**.
- P1·P2가 첫날 최우선인 이유: 결과에 따라 **모델의 변수 구성 자체가 달라짐**
  (취득 페널티 크면 "CAD 신선도"가 모델 입력에 추가되어야 함).
- 모든 런에서 tact 자동 수집(타임스탬프). 런시트에 Phase 0 시트 추가 사용.

## 산출물 (모델)
```
매칭모델:  매칭률 = g(kV−kV*, 범프px, CAD신선도)   ← P·A·B에서 각 축 분리 측정
품질모델:  Q_dia(kV) 직선 + void%오차(N) 곡선 + F 노이즈항
시간모델:  tact(R, F) 계수
운용규칙:  취득 = 절약세트(kV*, F32, R=B3/B4 결과로 확정) / 검사 = 모델 산출값
```
